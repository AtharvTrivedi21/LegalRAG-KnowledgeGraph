# phase4_rag

Purpose
- Implementation code for the RAG pipeline, retrieval interfaces, and Neo4j integration used in Phase 4.

What’s here
- Retrieval code: `vector_retriever.py`, `vector_retriever_v3.py`
- Neo4j clients and display utilities: `neo4j_client.py`, `neo4j_display_v2.py`
- Workflow helpers: `langgraph_workflow.py`, `langgraph_workflow_v3.py`

How to run
- Use `src/run_pipeline.py` or the RAG adapter scripts to run end-to-end retrieval + generation.

Notes
- This folder supports experiments with different retrieval configurations and Neo4j visualisations.
