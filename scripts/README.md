# scripts

Purpose
- Collection of utility scripts used across preprocessing, dataset preparation, and running experiments.

What’s here
- Helpers for PDF parsing, CSV validation, Neo4j import, and small test runners (e.g., `count_cases.py`, `verify_csvs.py`, `neo4j_load.py`).

How to use
- Read individual scripts for usage; many have short CLI helpers (or `.cmd` wrappers) in the repo root.
